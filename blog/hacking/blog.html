Account Access (devices)

This section covers how to access any account on devices. Different kinds of devices have different methods, so check it below:

Windows

On Windows, it is not that hard to get access to an account. First, you should figure out if it is a local or Microsoft account.

Check if the account has a profile picture that is not the default. If so, it is a Microsoft account. If not, it probably is local instead.

Note that if a user uses Windows Hello (PIN) you can NOT crack it.

If it is local, follow these steps:

  1. Click the icon at the bottom right.
  2. You will get some power options. Hold Shift AND DO NOT RELEASE IT UNTIL I TELL YOU.
  3. Click Restart. If it asks you to confirm restart, click "Restart Anyway"
  4. When the computer restarts, you should see "Please wait" in the bottom along with a spinner.
  5. You will now enter a recovery screen. This is usually blue, unless you are using Windows 11, where it might be black instead.
  6. Click Troubleshoot → Advanced Options → Command Prompt.
  7. If it asks you for a password, that means it was actually a Microsoft Account. Hold the button (on the computer) for 5 seconds to turn it off and follow the steps for Microsoft.
  8. Since it might not have asked you a password, you now have access to a Command Prompt!
  9. Type the command below, to get a new admin user:
    10. net user /add "enter a username" ""
  10. Now, close the Command Prompt. Click "Continue to this PC".
  11. You now have a new admin user. Choose it and sign in.
  12. From there, you can right click Start → Computer Management
  13. Open Local Users and Groups → Users and right click the target user to access.
  14. Click "Set Password...". This will show you a warning. Click proceed, and change the password.

If it is a Microsoft account, it becomes harder. But, if it has security questions, it becomes so much easier.

To figure out if it has security questions, enter a random password and try it. It most likely will say Password Incorrect. Now click "Reset password".

If it asks you security questions, that means the user has security questions enabled (obviously). If so, here is how to crack it:

  1. Shut down the computer.
  2. Open the computer physically and take out the HDD / SSD.
  3. Plug the HDD / SSD into your own computer (as a second drive).
  4. In your computer, press Windows + R and type 'cmd'. Hold Ctrl + Shift and click 'OK'
  5. It will ask "Do you want Windows Command Processor to make changes on your computer". Click Yes.
  6. Now, in Command Prompt, enter the following commands. Press Enter after typing each one:
  7. schtasks /create /tn SYS /tr "regedit.exe" /sc once /st 00:00 /rl highest /ru SYSTEM
  8. schtasks /run /tn SYS
  9. schtasks /delete /tn SYS /f
  10. After that, close Command Prompt. Registry Editor should be opened, so select it.
  11. On the side, you will see some options with an arrow. Use those to open HKEY_LOCAL_MACHINE → SAM → SAM → Domains → Accounts → Users.
  12. Next, open the Calculator on your computer. THE COMPUTER CALCULATOR IS NECESSARY.
  13. Calculate 1000 + the order of the user you want to hack (1 is 1st user created, 2 is 2nd, etc.) and note it down.
  14. Click the 3 lines icon, and pick "Programmer"
  15. In the "DEC" section, type the number you noted down from the calculation.
  16. Note down the result you get in the HEX section.
  17. Go back to the Registry Editor. You will see options like 000001F4, 000001F5 etc.
  18. Get your noted down HEX number and add 5 zeros at the start (so if you had 3E9, it will be 000003E9)
